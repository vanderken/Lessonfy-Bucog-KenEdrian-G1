## Routes

| URL | View | What |
|---|---|---|
| `/` | home | redirects to dashboard |
| `/dashboard/` | dashboard | lessons, progress, pin counts per collection |
| `/lessons/new/`, `/lessons/upload/` | create_lesson, upload_lesson | manual lesson, file or pasted text |
| `/lessons/<id>/` | lesson_detail | manage sections |
| `/lessons/<id>/read/` | reader | the reader |
| `/collections/` (+ `<id>/edit/`, `<id>/delete/`) | collections_list, collection_edit, collection_delete | collections |
| `/api/...` | JSON endpoints (POST only) | settings, pins, done, quick collection |
